# Реєстр джерел даних

Технічний список зовнішніх джерел, які використовує або перевіряє проєкт
`RDN Market Intelligence`. Цей файл потрібен для швидкого аудиту доступності,
назв аркушів і призначення кожного джерела.

## Google Sheets

аркушів, не записує формули й не змінює вихідні дані.

### Формат читання Google Sheets

Для публічних таблиць застосовується read-only CSV export Google Visualization:

```text
https://docs.google.com/spreadsheets/d/<SPREADSHEET_ID>/gviz/tq?tqx=out:csv&sheet=<SHEET_NAME>
```

Якщо джерело не відповідає, спочатку перевірити:

1. чи доступна сама таблиця за посиланням;
2. чи не перейменовано аркуш;
3. чи відповідає назва аркуша очікуваному місячному шаблону;
4. чи не змінилася структура колонок або блоків даних.

## Внутрішнє сховище

| Сховище | Призначення |
| --- | --- |
| Neon PostgreSQL через `DATABASE_URL` | Production-сховище нормалізованих даних і результатів імпорту |
| `data/market_forecast.sqlite3` | Локальний fallback; файл не комітиться в Git |

## Правила аудиту

- Не записувати в цей файл токени, паролі, `DATABASE_URL` або service-account JSON.
- Якщо змінюється ID таблиці або назва аркуша, оновити цей реєстр і відповідний loader в одному PR.
- Якщо джерело недоступне, не підміняти відсутні значення нулями.
- Для нової Google-таблиці додати пряме посилання, ID, очікувані аркуші та опис полів.
- Google Sheets залишаються authoritative source для відповідних внутрішніх імпортів.
